iptable hooks:
The Five Netfilter Hooks
• PREROUTING: Triggered as soon as a packet arrives and enters the network stack, before any routing decision is made (used for Destination NAT / DNAT).
• INPUT: Triggered when a packet's destination IP matches the local machine itself, meaning it is delivered to local user-space processes.
• FORWARD: Triggered when a packet is not addressed to the local machine, but is instead routed or passed through to another network interface.
• OUTPUT: Triggered when a local application or process generates an outgoing network packet before it undergoes a routing decision.
• POSTROUTING: Triggered right before a packet physically leaves the network interface, after all routing decisions are finalized (used for Source NAT / SNAT)
